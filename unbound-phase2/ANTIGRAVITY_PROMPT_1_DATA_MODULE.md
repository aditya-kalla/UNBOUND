## Task C - implement the repositories (package com.unbound.data.repo.impl)
Implement `LibraryRepository`, `PlaylistRepository`, `QueueRepository`, `StatsRepository`, `TelemetryWriter`, plus `SqlDelightLibraryWriter : LibraryWriter`. Use SQLDelight `asFlow().mapToList(dispatcher)`. Add any extra queries you need to the `.sq` files (keep the existing ones unchanged); every new query must also run in `tools/validate_sql.py` style or have a test. Rules:
- **Writer.applyBatch** = ONE transaction: for each ParsedFile -> upsert artwork (INSERT OR IGNORE + select id) -> artists (split `ParsedTrack.artists`; if it has one element use `ArtistSplitter`; MAIN/FEATURED roles, position order) -> album (`album_key = matchKey(title) + "|" + matchKey(albumArtist ?: first artist ?: "")`; album artist falls back to the first artist) -> `upsertTrack` -> rewrite `track_artist` + `track_genre` (delete then insert) -> rewrite the `track_search` row (title, artist display, album, genres) in the same transaction. Fallbacks: title = file name without extension; artist "Unknown Artist"; album "Unknown Album". `title_sort`/`name_sort` via `sortKey`, identity via `matchKey`. Genres: split on `;` only (never `/`: "R&B/Soul"). `artist_display` = the raw joined artist string as tagged.
- **Relink** = `relinkTrack` (keeps id) and refresh metadata fields the same way as an upsert but WITHOUT creating a new row. `finishScan` = prune empty albums/artists/artwork + stamp source. `markMissing` also leaves playlist/queue/like rows intact.
- **removeSource**: flag its tracks missing, delete the source row. Adding the same folder later must resurrect them (same uri => upsert path).
- **Search**: sanitise the user's text for FTS5 (quote tokens, append `*` to the last token, escape quotes); empty query returns empty list. Add the query to search history only when asked (`addSearchHistory`).
- **Playlists**: `addTracks` uses `PositionAllocator.append`; `moveEntry` uses `PositionAllocator.between(prevPos, nextPos)` and when it returns null renumbers via `playlistItemIdsOrdered` + `setItemPosition` inside one transaction, then retries. Pin limit constant `MAX_PINNED = 4`; `setPinned` returns false when exceeded. Folder deletion must not delete playlists (they move to root, `ON DELETE SET NULL` already does it).
- **Queue**: `replaceQueue(trackIds, startItemIndex, context, shuffle)`: positions 1024*i, `original_position` = unshuffled index; if shuffle, Fisher-Yates over the OTHER items and put the start item first. `playNext` inserts after the current item and after any earlier USER-origin items, using `between`. `addToEnd` appends. `setShuffle(true)` reshuffles only items after the current one; `setShuffle(false)` restores `original_position` order for items after the current one while keeping played history. `getState/saveState` read/write `player_state` (clamp `speed` to 0.5..2.0).
- **TelemetryWriter**: Channel(UNLIMITED) + one writer coroutine; flush when 50 events are buffered, after 2 s, or immediately when an END event arrives; `flush()` suspends until the channel is drained; each flush is one transaction. Must never block the caller.
- **StatsRepository**: thin mapping over `Stats.sq`. `topTracksInHourWindow` accepts any 0..24 window including wrap-around.
